# Scratch programs
Per-piece programs prove a construct on both full kernels, stack8 and microcode7.
Place each program at `<piece>/<name>.py` with its expected `<name>.out` or `<name>.err`.
The `scratch` job runs every program on both full kernels and checks its expected output or error.
These programs are not part of `test.sh`, which compares all six kernels.
