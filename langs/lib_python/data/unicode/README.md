Unicode character properties and normalization mappings: Unicode 16.0.0 UCD UnicodeData.txt and DerivedNormalizationProps.txt (Unicode Terms of Use); frozen Unicode 3.2 from CPython unicodedata.ucd_3_2_0 (PSF license). Layout: three little-endian u32 counts; 12-byte property ranges (u32 start/end, category/bidi/combining/mirrored bytes); 16-byte decomposition records (u32 codepoint, compatibility, pool offset, length); 12-byte composition records (u64 pair key, u32 result); u32 decomposition pool. Hangul normalization is algorithmic. Category and bidi indices follow the arrays in each kernel native adapter.
